# Technical plan — Spec 006

Spec: `specs/006-sdd-vault-staging/spec.md` · Constitution: v3.0 · Date: 2026-10-24

## 1. Summary

A mechanical, ordered rename of every identifier (hostnames first, then the kebab, snake, screaming and
title forms), file and folder renames for the Keycloak realm and theme, the CLI binary renamed to
`sddvault`, the brand assets of the handoff copied into `packages/ui` and served by the landing, the app
and the Keycloak theme. The CD repository is renamed to `sdd-vault-cd`, published on GitHub under
`eduinlight-org`, and its manifests follow the same rename. The staging namespace, its secrets, a Garage
key and bucket, and the ArgoCD Application are created once by hand (recorded in the CD README), and the
GitHub repository is renamed to `eduinlight/sdd-vault`.

- Request header `X-Sdd-Vault-Request` for the app's CSRF check.

## 7. Decisions

- **Rename the GitHub repository** (owner chose "everything"); rejected: keep `spec-store` — the owner asked
  for the full rename. GitHub redirects the old remote URL, so open clones keep working.
- **Literal ordered replacement** instead of hand edits: 600+ occurrences; the ordering avoids partial
  matches (hostnames before the bare name).
- **Historical specs untouched**: they record what was decided under the old name.
- **SMTP**: staging uses the Amazon SES relay credentials already present in the cluster (eu-west-3, port
  587, STARTTLS); rejected: an in-cluster relay account, which needs mailbox provisioning.
- **Object storage**: a Garage key `sdd-vault-staging` and bucket `sdd-vault-staging` on the homelab Garage
  (`192.168.0.5:3900`, region `garage`), stored as `object-storage-credentials`; used by later tickets.

## 8. Security

Secrets are generated by `scripts/create-secrets.sh` in the cluster; nothing is committed. The Garage key
is scoped to its bucket.

## 9. Test strategy

Existing suites with the new names (`make lint`, `make fmt-check`, `make test`, `make e2e`); a grep check
that no visible "Spec Store" remains; the pipeline and the staging hostnames checked after the merge.
